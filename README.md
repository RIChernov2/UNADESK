# Test Assignment for UNADESK

---

## Task Description:

You need to create a library with a single method that determines
whether a triangle is acute-angled, right-angled, or obtuse-angled
based on its three sides. The method should be highly efficient and
capable of handling non-integer side lengths. The result should be
uploaded to GitHub. Tests are also welcome.

Info:
- An **acute-angled triangle** is a triangle where all angles are acute (less than 90 degrees).
- A **right-angled triangle** is a triangle where one of the angles is exactly 90 degrees.
- An **obtuse-angled triangle** is a triangle where one of the angles is obtuse (greater than 90 degrees).
